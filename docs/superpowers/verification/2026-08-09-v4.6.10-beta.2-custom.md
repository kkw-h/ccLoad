## 已确认兼容性影响

该行为不影响普通 `logs`、Token、渠道、模型和 300 秒非流式超时，但属于部署前必须明确接受或另行处理的破坏性变化。本轮不修改官方 beta 的调试日志保留策略。

因此当前分支可以用于继续评审和制定上线方案，但生产部署状态为阻塞：必须先决定保留、迁移或接受清理这些历史调试日志。

## 原模型推理强度能力扩展

同日继续在隔离分支完成模型能力发现功能；本节代码尚未部署到线上。实现以渠道 `redirect_model` 指向的原模型为依据，在 OpenAI、Codex 和 Anthropic 形态的 `/v1/models` 模型对象中增量返回 `supported_reasoning_efforts`。内建的 `gpt-5.6-sol` 能力为 `low`、`medium`、`high`、`xhigh`；`sciland-3.0 → gpt-5.6-sol` 因而自动继承该集合。

行为与隔离语义验证：

- 多个可见渠道将同一公开名称映射到不同原模型时返回能力交集。
- 任一候选原模型能力未知时省略字段；管理员明确配置空数组时返回 `[]`。
- 先应用 API Token 的渠道和模型限制，再聚合能力，受限渠道不会影响结果。
- `/v1beta/models` 保持原响应，不增加该字段；`redirect_model` 不对外暴露。
- 全局设置 `model_reasoning_effort_overrides` 支持管理后台编辑和热更新；单独保存不重启，混合修改仍按原规则重启。
